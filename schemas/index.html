JSON Schemas

Machine-readable definitions for all IAES v1.1 event types. Use these to validate events in your pipeline.

Common Envelope

Base envelope shared by all IAES v1 events. Defines spec_version, event_type, event_id, correlation_id, timestamp, source, content_hash, and asset identity.

envelope.json

asset.measurement

Physical sensor reading from an industrial asset. Required fields: measurement_type, value, unit.

measurement.json

asset.health

AI diagnosis, rule engine alert, or human expert health assessment. Required fields: health_index, severity.

health.json

maintenance.work_order_intent

Declares intent to create a maintenance work order. Required fields: title, priority.

intent.json

maintenance.completion

Work order completion acknowledgment with outcome details. Required fields: status, work_order_id.

completion.json

asset.hierarchy

Asset hierarchy structure sync — organizations, plants, areas, and equipment. Required fields: hierarchy_level, relationship_type.

hierarchy.json

sensor.registration

Sensor discovery, onboarding, and lifecycle events. Required fields: sensor_id, registration_status.

sensor-reg.json

maintenance.spare_part_usage

Spare parts consumed during maintenance activities. Required fields: work_order_id, spare_part_id, quantity_used.

spare-parts.json

Validation Example

Use any JSON Schema validator (Python, Node.js, Go, etc.):

pip install jsonschema

python -c "
import json, jsonschema
schema = json.load(open('iaes-envelope.schema.json'))
event  = json.load(open('../examples/asset-health-ai.json'))
jsonschema.validate(event, schema)
print('Valid IAES event')
"
