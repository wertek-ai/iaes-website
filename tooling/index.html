from iaes import Client, AssetMeasurement client = Client("https://your-endpoint.com", api_key="key") event = AssetMeasurement( asset_id="MOTOR-001", measurement_type="vibration_velocity", value=4.2, unit="mm/s", source="acme.sensors", ) result = client.publish(event)

5 Minutes to Your First Event

Three steps from zero to a validated IAES event.

1

Install the SDK

Pick your language and install via your package manager.

pip install iaes # or npm install @iaes/sdk
2

Create an Event

Wrap your measurement in an IAES envelope.

{ "specversion": "2.0", "type": "asset.measurement", "source": "acme.sensors", "id": "evt-001", "data": { "asset_id": "MOTOR-001", "measurement_type": "vibration_velocity", "value": 4.2, "unit": "mm/s" } }
3

Publish

Send via HTTP, MQTT, or any transport you prefer.

# HTTP POST curl -X POST https://your-endpoint.com/iaes \ -H "Content-Type: application/json" \ -d @event.json # or MQTT mosquitto_pub -t iaes/events \ -f event.json

Developer Tools

Validate, inspect, route, and debug IAES events from the command line.

⌨

iaes-cli

Validate events, generate samples, and publish to MQTT or HTTP from the terminal.

# Validate an event file $ iaes validate event.json # Generate a sample event $ iaes generate asset.measurement # Publish to MQTT broker $ iaes publish event.json --broker mqtt://localhost
Planned
🔍

iaes-inspector

Real-time event stream viewer with schema validation, filtering, and correlation tracking.

# Start inspector UI $ npx iaes-inspector # Connect to MQTT stream $ npx iaes-inspector --broker mqtts://mqtt.example.com # Filter by event type $ npx iaes-inspector --type asset.health
Planned
🔌

iaes-router

Event fan-out engine. Route IAES events to multiple destinations based on type, severity, or asset.

# Run with config file $ iaes-router --config routes.yaml # Or run as Docker container $ docker run -v routes.yaml:/config.yaml \ iaes/router:latest
