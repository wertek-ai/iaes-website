from iaes import Client, AssetMeasurement client = Client("https://your-endpoint.com", api_key="key") event = AssetMeasurement( asset_id="MOTOR-001", measurement_type="vibration_velocity", value=4.2, unit="mm/s", source="acme.sensors", ) result = client.publish(event)

5 Minutes to Your First Event

Three steps from zero to a validated IAES event.

1

Install the SDK

Pick your language and install via your package manager.

pip install iaes # or npm install @iaes/sdk
2

Create an Event

Wrap your measurement in an IAES envelope.

{ "specversion": "1.3", "type": "asset.measurement", "source": "acme.sensors", "id": "evt-001", "data": { "asset_id": "MOTOR-001", "measurement_type": "vibration_velocity", "value": 4.2, "unit": "mm/s" } }
3

Publish

Send via HTTP, MQTT, or any transport you prefer.

# HTTP POST curl -X POST https://your-endpoint.com/iaes \ -H "Content-Type: application/json" \ -d @event.json # or MQTT mosquitto_pub -t iaes/events \ -f event.json

Validate Your Events

Every IAES event type has a JSON Schema. Validate before publishing to catch errors early.

import jsonschema from iaes import get_schema schema = get_schema("asset.measurement") jsonschema.validate(event, schema) # raises on invalid

Schemas are also available as standalone JSON files at /schemas/ for use with any language or validator.
