IAES Nodes for n8n

Three purpose-built nodes that bring industrial event intelligence into your n8n workflows.

IAES Emit

IAES Emit

Wrap any data into a valid IAES event envelope. Accepts raw sensor readings, PLC values, or HTTP payloads and outputs a standards-compliant IAES event.

IAES Validate

IAES Validate

Validate incoming JSON against IAES v1.3 schema. Routes valid events to the success output and invalid events to the error output for review.

IAES Lifecycle

IAES Lifecycle

Track onset, escalation, and recovery state machine. Correlates events by asset and automatically detects incident progression and resolution.

Getting Started

From zero to industrial automation in three steps.

1

Install n8n

Run n8n locally or on your server with a single command.

npx n8n
2

Install IAES Nodes

Add the IAES community nodes to your n8n instance.

npm install n8n-nodes-iaes
3

Import a Workflow

Start from a template workflow. Configure your MQTT broker, point to your assets, and activate.

Settings → Community Nodes → n8n-nodes-iaes
