SDKs

Validated event construction in your language. Type-safe, schema-aware, zero dependencies.

🐍

Python

Dataclass-based models with Pydantic validation. Serialize to JSON, publish to MQTT or HTTP.

# Install pip install iaes
from iaes import Measurement event = Measurement( asset_id="pump-001", metric="vibration_rms", value=4.2, unit="mm/s" ) print(event.to_json())
TS

TypeScript

Full type definitions with Zod schema validation. Tree-shakeable ESM exports.

// Install npm install @iaes/sdk
import { createMeasurement } from '@iaes/sdk'; const event = createMeasurement({ asset_id: 'pump-001', metric: 'vibration_rms', value: 4.2, unit: 'mm/s', });
NR

Node-RED

Drag-and-drop nodes: iaes-measurement, iaes-health, iaes-validate, iaes-format.

# Install in Node-RED npm install node-red-contrib-iaes
// msg.payload output { "specversion": "1.3", "type": "asset.measurement", "data": { "metric": "vibration_rms", "value": 4.2 } }

Developer Tools

Validate, inspect, route, and debug IAES events from the command line.

⌨

iaes-cli

Validate events, generate samples, and publish to MQTT or HTTP from the terminal.

# Validate an event file $ iaes validate event.json # Generate a sample event $ iaes generate asset.measurement # Publish to MQTT broker $ iaes publish event.json --broker mqtt://localhost
Planned
🔍

iaes-inspector

Real-time event stream viewer with schema validation, filtering, and correlation tracking.

# Start inspector UI $ npx iaes-inspector # Connect to MQTT stream $ npx iaes-inspector --broker mqtts://mqtt.example.com # Filter by event type $ npx iaes-inspector --type asset.health
Planned
🔌

iaes-router

Event fan-out engine. Route IAES events to multiple destinations based on type, severity, or asset.

# Run with config file $ iaes-router --config routes.yaml # Or run as Docker container $ docker run -v routes.yaml:/config.yaml \ iaes/router:latest
